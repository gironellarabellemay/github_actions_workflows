# GitHub Actions Workflows

A Cloud Engineer Academy project focused on learning GitHub Actions workflow automation, including push events, pull request validation, and cleanup automation.

This repository was created to practise how DevOps and platform engineering teams use GitHub Actions to automate checks and reduce manual work during development.

## Project Overview

The goal of this project was to learn how GitHub Actions workflows can be triggered by repository events such as pushes, pull requests, and merges.

This project helped me understand the basics of workflow files, triggers, jobs, and automated checks in GitHub.

## What This Project Demonstrates

* Creating GitHub Actions workflow files
* Using repository events (push, pull request, merge) to trigger automation
* Understanding pull request validation workflows
* Practising cleanup automation after merge events
* Learning how CI/CD pipelines support software and infrastructure delivery
* Troubleshooting workflow syntax and execution errors
